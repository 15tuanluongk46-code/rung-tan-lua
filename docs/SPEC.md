## Integration contract
Primary owns assets generator, assets/, scripts/world_art.gd, scripts/actor_visual.gd, scripts/audio_director.gd. Worker owns gameplay scripts, tests, project.godot configuration and UI, not those files.
- World is 2400x1600. Region centers: camp(420,380), forest(1720,380), creek(520,1190), ruins(1810,1190). Player start(430,450). Continuous connected walkable map.
- `scripts/world_art.gd` extends Node2D. Main calls `build(world: Node2D) -> void` ONCE; adds terrain, props and StaticBody2D collisions to world; exposes `obstacles: Array[Rect2]` and `is_blocked(point: Vector2, margin: float=0.0) -> bool`. Roads/region centers remain clear; props placed away from roads. World node must have y_sort_enabled=true. Background z_index=-20. WorldArt root at origin.
- `scripts/actor_visual.gd` extends Node2D. `setup(kind: String) -> void`, `pose(facing: Vector2, moving: bool, action: String, elapsed: float) -> void`. Kinds: player, chief, hunter, healer, smith, gatherer, melee, archer, shaman, bear, deer, rabbit, bird. Actions idle/run/attack/dodge/throw/hurt/dead/work/flee. Sprite sheets res://assets/sprites/{kind}.png 48x48 cells, columns6, rows4 (down,left,right,up), frames0idle1-3walk4action5hurt. ActorVisual adds own grounded shadow, renders foot at local(0,0), animations/held tools via art. `flash` property float optionally decays worker side; pose may manage own modulate. Actual renderer must animate even if no action.
- `scripts/audio_director.gd` extends Node. `play_sfx(key: String, world_position: Vector2=Vector2.ZERO)`, `set_region(region: String)`; keys step, attack, hit, dodge, stone, pickup, heal, quest, death, click. Creates Music/SFX buses if absent, Master built-in; public `set_volume(bus: String,value: float)` 0..1, settings managed worker.
- Font path res://assets/fonts/DejaVuSans.ttf. Primary provides trees/props/terrain and ambient lighting. Worker supplies player PointLight2D if possible or primary can integrate afterward.
- Root scene scenes/Main.tscn created via Godot MCP by primary; worker sets script res://scripts/main.gd afterward via code/config patch. No worker MCP scene editing required unless tool available. Worker can create UI dynamically through scripts, separate responsibility files.

## Execution decisions

- Original custom pixel art generated by checked-in deterministic Python/Pillow drawing source is licensed with project; no external sprite provenance ambiguity. Must be judged visually, not assumed adequate. Fonts use system DejaVu with license copied.
- Godot export templates currently absent. Download official matching templates if available; never mislabel an editor-binary launcher as an export.
